# Swati Mehendale – Executive FinTech Portfolio

An executive-level portfolio website for **Swati Mehendale**, an experienced Techno-Functional Business Analyst & Product Owner with 20+ years of institutional BFSI excellence across Investment Banking, Asset Management, Fund Administration, and Alternative Investments.

Designed with a sleek **"Shiny Black" (Luxury Obsidian & Glassmorphism)** aesthetic, featuring specular light highlights, subtle fintech background particle animations, responsive career timeline across 8 positions (2003–2025), interactive architectural case studies, competency matrix, and a printable executive curriculum vitae.

## 🛠️ Tech Stack & Architecture

- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite v8
- **Styling**: Tailwind CSS v4 + Custom Obsidian Glassmorphism Utilities
- **Icons**: Lucide React + Custom SVG Monograms
- **Graphics**: HTML5 Canvas Particle Engine (`FintechBackground.tsx`)
- **Print Support**: Dedicated CSS print stylesheet for 1-click executive CV generation

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/rohantheediter-source/Swati-Mehendale.git

# Navigate into the project directory
cd Swati-Mehendale

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be live at `http://localhost:5173/`.

### Production Build

```bash
npm run build
```

The optimized static files will be generated in the `dist/` directory.
